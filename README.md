# Мой первый проект

Учебный репозиторий для практики Git и Markdown.

## Описание

Это мой первый проект в рамках курса. Здесь я учусь:

- работать с Git
- писать документацию в Markdown

## Содержание

1. [hello.txt](hello.txt) — первый файл
2. [notes.txt](notes.txt) — заметки
